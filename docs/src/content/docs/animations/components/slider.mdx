`aa-slider` turns a list of `[aa-slider-item]` elements into a seamless looping carousel powered by GSAP's `horizontalLoop` helper. Modes are space-separated tokens inside the attribute value; combine freely.

## Modes

`aa-slider` modes:

| Token             | Effect                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| (empty)           | Basic slider; prev/next + thumb buttons advance one slide. No autoplay, no drag.                      |
| `draggable`       | Mouse + touch drag with InertiaPlugin throw, snaps to nearest slide.                                  |
| `center`          | Centers the active slide horizontally in the container.                                               |
| `finite`          | Non-looping track with hard start/end bounds. Prev/next and keyboard clamp at the first/last slide (arrow buttons get `.is-disabled` + `aria-disabled` there); drag is bounded; autoplay rewinds to the first slide at the end. Combines with `center` and `draggable`. |
| `none`            | Don't init at this breakpoint. Combine with the `\|` shorthand (splits at `md`) or any of the `-sm` / `-md` / `-lg` / `-xl` suffix attributes for responsive on/off. |

Autoplay is configured separately via the standalone `aa-autoplay` attribute — see [Config attributes](#config-attributes).

```html
<div aa-slider="draggable center" aa-duration="0.6" aa-autoplay="3 hover-pause">…</div>

<!-- Bento on desktop, autoplay carousel on mobile -->
<div aa-slider="none|" aa-autoplay="none|3">…</div>
```

## Config attributes

| Attribute     | Default               | Notes                                                                  |
| ------------- | --------------------- | ---------------------------------------------------------------------- |
| `aa-duration` | (init)                | Seconds for each slide transition.                                     |
| `aa-autoplay` | (off; init `interval` when present) | See [Autoplay](#autoplay) below. Drives the per-slide dwell + progress-bar fill. |
| `aa-ease`     | (init)                | Any GSAP ease — used for transitions and progress bars.                |

### Autoplay

Autoplay is configured via the standalone **`aa-autoplay`** attribute, shared with `aa-tabs` so the same configuration shape applies uniformly across components (and `aa-delay` keeps its meaning of "tween start delay" everywhere).

| Attribute     | Value                 | Effect                                                                                          |
| ------------- | --------------------- | ---------------------------------------------------------------------------------------------- |
| `aa-autoplay` | (absent)              | No autoplay.                                                                                    |
| `aa-autoplay` | (present, no value)   | Autoplay at the init default interval (default 4s). No hover-pause.                             |
| `aa-autoplay` | `"3"`                 | Autoplay with a 3s dwell per slide.                                                             |
| `aa-autoplay` | `"3 hover-pause"`     | 3s dwell; `mouseenter` pauses, `mouseleave` resumes (non-touch only).                           |
| `aa-autoplay` | `"3\|none"`           | Autoplay on desktop, off on mobile (`\|` splits at `md`; `-sm`/`-md`/`-lg`/`-xl` also work).    |

## Structural attributes

| Attribute             | What it marks                                                              |
| --------------------- | -------------------------------------------------------------------------- |
| `aa-slider`           | Slider root.                                                               |
| `aa-slider-item`      | Each slide. Keep it as a thin flex wrapper — put visual styling on a child element so borders/shadows don't get caught by the slider's transform math. |
| `aa-slider-prev`      | Previous-slide button.                                                     |
| `aa-slider-next`      | Next-slide button.                                                         |
| `aa-slider-button`    | Thumbnail / pagination button. Index inferred from DOM order.              |
| `aa-slider-target`    | When set on an external `aa-slider-button`, references the slider's `id`.  |
| `aa-slider-current`   | Element whose text content reflects the current 1-based slide index.       |
| `aa-slider-total`     | Element whose text content reflects the total slide count.                 |
| `aa-slider-progress`  | Inside `aa-slider-button`, fills over the resolved `aa-autoplay` interval. Value is `width` (default), `height`, or `circle`. For `circle`, mark an SVG (or place an SVG inside the marked element) — the lib finds the inner `<circle>` and tweens its `stroke-dashoffset` from full circumference to zero. |

## Required GSAP plugins

`gsap`, `ScrollTrigger`, `Draggable`, `InertiaPlugin`.

## Animations triggered by slide activation

`aa-animate` elements inside an `[aa-slider-item]` are **automatically driven by slide activation**: they play when the slide becomes active and reverse when it becomes inactive. No `aa-trigger` attribute needed — the slider emits `slide-active` / `slide-inactive` events on each slide and the closest container ancestor is the inferred trigger.

```html
<div aa-slider aa-autoplay="3">
  <div class="track">
    <div aa-slider-item>
      <div class="slide-card">
        <h2 aa-animate="fade-up">Headline</h2>   <!-- inferred: event:slide-active -->
      </div>
    </div>
  </div>
</div>
```

If you need to opt out — e.g. an animation inside a slide that should still respond to scroll position — set `aa-trigger="scroll"` explicitly to override the inference.

Inference is breakpoint-aware: in a range where `aa-slider` resolves to `none` (e.g. the `aa-slider="none|"` bento-on-desktop pattern), the slider never emits `slide-active`, so the in-slide animations fall back to scroll automatically — no `aa-trigger` needed.

## Keyboard navigation

When the slider has focus, **Arrow Left** / **Arrow Right** step backwards / forwards, **Home** jumps to the first slide, **End** to the last. The slider root gets `tabindex="0"` automatically.
